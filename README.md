# CRAFFONARA FX — handmade guitar pedals by Walter Craffonara

Boutique guitar effects pedals, true bypass mods and MIDI relay retrofits,
designed and hand-built by **Walter Craffonara** in Austria.

**Website:** https://wcraffonara.github.io/craffonara-fx/

Walter Craffonara builds quad-preset pedals with relay-switched presets and
MIDI TRS control — four complete settings in one enclosure — plus the
CRAFFONARA FX MIDI Filter, a compact 5 x 5 x 3 cm MIDI message filter.

- Custom builds and one-off circuits
- Relay true bypass conversions
- MIDI retrofits (TRS, Type A)
- User manuals for every build: see `manuals/`
